# GenPopUtils

**Simple, useful tools built for developers, creators, and everyday use.**

GenPopUtils is a collection of focused web utilities designed to solve specific problems quickly — without unnecessary complexity.

## 🛠️ Tools

| Tool | Description | Website |
|---|---|---|
| **Regex Tester** | Test, learn, and explore regular expressions with presets and a handy cheat sheet. | [regex.genpoputils.com](https://regex.genpoputils.com) |
| **Compound Calculator** | Calculate compound interest, investment growth, SIPs, step-up investments, and more. | [compoundcalc.genpoputils.com](https://compoundcalc.genpoputils.com) |

## 🚀 What's Next

## 🎯 Our Approach

Every GenPopUtils tool is designed around a few principles:

- **Simple** — get the result without unnecessary complexity.
- **Fast** — lightweight and responsive.
- **Useful** — built around real-world problems.
- **Privacy-friendly** — prefer client-side processing wherever possible.
- **Free to use** — practical tools should be accessible to everyone.
